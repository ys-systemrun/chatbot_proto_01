## 分かったこと（ゴールデンセットの外の問題）

言い換え質問文（`hiroba_question_altered`）から無作為に選んだ30問のうち、**10問が無関係な QA に紐づき、2問が曖昧**だった。
言い換え質問文は検索の索引そのものなので、誤った紐づけは本番の検索でも無関係な QA を上位に引き寄せうる。
上に挙げた QA ID は、言い換え質問データ全体の点検（改善候補）の出発点として使う。
