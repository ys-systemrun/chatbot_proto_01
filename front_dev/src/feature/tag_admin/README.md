# front_dev/src/feature/tag_admin/ — タグ階層管理画面とタグ選択部品

管理サブナビ「タグ」から開くタグ階層管理画面（`/admin/tags`）と、QA・トラブルシューティング画面でも使うタグピッカー。
タグ検索・フォルダ別表示・類似候補チェックはバックエンド API を増やさずクライアント側で計算する（ADR-0070 / ADR-0071 / ADR-0072）。画面遷移図の 3.9 節を参照。

## 構成

| 名前 | 説明 |
|---|---|
| [`TagTreePage.tsx`](TagTreePage.tsx) | タグ階層画面。タグの作成・編集・削除・兄弟内の並べ替え（↑/↓, ADR-0074）、エイリアスの追加・編集・削除（ADR-0080、入力中の類似候補表示 ADR-0082）、タグフォルダの作成・編集・移動・並べ替え・削除（ADR-0072/0073）、検索・絞り込み、新規作成名の類似候補チェック、CSV インポート/エクスポートを持つ。 |
| [`TagPicker.tsx`](TagPicker.tsx) | タグ階層をチェックボックス一覧で選ぶ共通部品。タグ名・エイリアスの検索（一致タグを祖先パンくず付き表示）と、未絞り込み時のタグフォルダ別・階層インデント表示を持つ。QA 一覧/フォーム・トラブルシューティング一覧/編集フォームで使用。 |
| [`tagFilter.ts`](tagFilter.ts) | タグ関連の純粋ロジック。文字の正規化（NFKC＋小文字化）、パンくず付き絞り込み、タグフォルダの平坦化とフォルダ別グルーピング、Levenshtein 距離による類似候補検出（`findSimilarTags`）。`TagTreePage`・`TagPicker` から利用。 |
