# docs/implementation_handoff — 実装指示書

要件定義書（[`../requirement/`](../requirement/README.md)）と ADR（[`../adr/`](../adr/README.md)）で確定した方針を、実装担当者（開発者またはコーディングエージェント）が着手できる粒度まで具体化した指示書を置くフォルダです。
各指示書はソースコードを含まず、インターフェース仕様・作業手順・設定値の指示にとどめます。文書番号は `IMPL-<ファイル名の日時>`。2026-08-21 以前の指示書はファイル名が `<日時>_implementation.md` で、題名は本文の見出しにあります。
なお、時期によって `db_hiroba_qa_init`・`chatbot`/`db_hiroba_qa` などの旧名称が使われています（現在の名称は ADR-0069・0077・0098 を参照）。
