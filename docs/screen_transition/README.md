# docs/screen_transition — 画面遷移図

front_dev（React + react-router-dom の SPA）の画面遷移図と、そこから参照する画面スクリーンショットを置くフォルダです。
画面を追加・削除・変更したときは、同じ変更の中で画面遷移図とスクリーンショットも更新します（リポジトリルートの `CLAUDE.md` 参照）。

## 構成

| 名前 | 説明 |
|---|---|
| [`画面遷移図.md`](画面遷移図.md) | 画面遷移図の本文。画面グループ全体像とルート定義一覧（`front_dev/src/routes.tsx` と 1 対 1）、Mermaid による詳細遷移図、13 画面のスクリーンショット付き説明 |
| [`screenshots/`](screenshots/README.md) | 画面遷移図から参照する実画面のスクリーンショット（`NN_画面名.png`）と対応表 |
