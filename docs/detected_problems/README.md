# docs/detected_problems — 検出された問題の調査報告

運用・検証中に見つかった不具合や想定外の挙動について、現象・調査経過・原因・対応方針をまとめた調査報告を置くフォルダです。
ファイル名は `YYYYMMDDhhmm_<題名>.md`。調査結果に基づく設計変更は ADR（[`../adr/`](../adr/README.md)）や要件定義書（[`../requirement/`](../requirement/README.md)）として別途起票します。
