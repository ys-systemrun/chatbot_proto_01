# docs/requirement — 要件定義書・検討メモ

機能追加や構成変更ごとに、目的・スコープ・要件・Open Issue を整理した要件定義書を置くフォルダです。あわせて、要件定義の前段となる構成検討メモと、担当者向けの運用ガイドラインも置いています。
ファイル名は `YYYYMMDDhhmm_<題名>.md` で、文書番号は `REQ-<日時>`。要件定義書から導いた設計判断は [`../adr/`](../adr/README.md)、実装手順は [`../implementation_handoff/`](../implementation_handoff/README.md) にあります。
時期によって `db_hiroba_qa_init`・`db_hiroba_qa`・`hiroba_tag` などの旧名称が使われています（現在の名称は ADR-0069・0077・0098 を参照）。
